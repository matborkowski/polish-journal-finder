
# Polish Journal Finder

Polish Journal Finder is a free, open-source web application designed to help researchers find scientific journals included in the official Polish ministerial journal lists.

## Project Objective

The main goal is to provide an accurate, comprehensive, and user-friendly search tool for scientific journals based on their ministerial evaluation scores and assigned scientific disciplines.

The project prioritizes data accuracy, completeness, and transparency.

## Key Features

Planned functionality includes:

- Searching journals by title and ISSN/e-ISSN.
- Filtering journals by scientific discipline.
- Filtering journals by ministerial evaluation score.
- Combining multiple search criteria.
- Exporting filtered journal lists.
- Supporting updated ministerial journal lists.

## Data Source

The initial dataset is based on the official Polish ministerial list of scientific journals published in January 2024.

Future versions will support newer official lists as they become available.

## Development Roadmap

1. Analyze and validate the source dataset.
2. Develop the journal search and filtering engine.
3. Implement automated tests.
4. Develop a user-friendly web interface.
5. Deploy the application.
6. Introduce optional AI-assisted journal recommendations based on manuscript titles, abstracts, and keywords.

## Project Status
